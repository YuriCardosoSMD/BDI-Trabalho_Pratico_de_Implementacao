# BDI-Trabalho_Pratico_de_Implementacao
Desenvolver uma aplicação, de tema livre, que manipule dados em um Banco de Dados Relacional
– O Banco de Dados Relacional deverá possuir, no mínimo, cinco tabelas, cinco chaves primárias e três chaves estrangeiras
• Cada tabela deverá possuir, no mínimo, duas colunas
– A aplicação deverá submeter, no mínimo, as seguintes operações SQL DML ao Banco de Dados Relacional:
• Cinco operações de leitura (SELECT)
• Três operações de inserção (INSERT)
• Duas operação de atualização (UPDATE)
• Duas operação de remoção (DELETE)
