# BDI — Trabalho Prático de Implementação

Desenvolver uma aplicação, de tema livre, que manipule dados em um **Banco de Dados Relacional**.

## Requisitos mínimos

### Banco de Dados Relacional

- Possuir, no mínimo, **cinco tabelas**
- Possuir, no mínimo, **cinco chaves primárias**
- Possuir, no mínimo, **três chaves estrangeiras**
- Cada tabela deve possuir, no mínimo, **duas colunas**

### Operações SQL DML

A aplicação deverá submeter ao Banco de Dados Relacional, no mínimo:

| Operação | Mínimo |
| --- | :---: |
| Leitura (`SELECT`) | 5 |
| Inserção (`INSERT`) | 3 |
| Atualização (`UPDATE`) | 2 |
| Remoção (`DELETE`) | 2 |
